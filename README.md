# Dry Bean Multiclass Classification

Projeto da disciplina CIN0144 - Aprendizado de Máquina e Ciência de Dados.

Objetivo:
Construir e comparar modelos de classificação multiclasse para identificar tipos de feijão utilizando o Dry Bean Dataset.

Etapas:
● Realizar uma análise exploratória para entender a distribuição de cada classe e
visualizar a separabilidade dos dados (e.g., usando PCA ou t-SNE).

● Aplicar técnicas de pré-processamento e, se necessário, de feature engineering para
melhorar a representação dos dados e o desempenho dos modelos.

● Verificar o balanceamento entre as múltiplas classes e discutir o impacto que um
eventual desbalanceamento pode ter nas métricas de avaliação.

● Justificar a escolha de cada algoritmo com base nas suas premissas e na natureza
dos dados.

● Realizar o processo de busca e ajuste de hiperparâmetros para cada modelo,
visando maximizar a métrica de avaliação principal escolhida.

● Avaliar e comparar os modelos usando no mínimo 3 métricas adequadas para o
cenário multiclasse (ex: Acurácia, F1-Score Ponderado/Macro, Coeficiente Kappa de
Cohen).

● Gerar e analisar a matriz de confusão para cada modelo, identificando quais classes
são mais frequentemente confundidas entre si e discutindo possíveis causas.
